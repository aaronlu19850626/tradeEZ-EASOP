# TradeEZ-SOP 第五项测试说明

> 测试环境：MT5 模拟账户、对冲账户模式  
> 测试对象：`tradeEZ.ex5`，源码最后修改时间 2026-09-19 02:06（北京时间）

## 1. 测试前准备

1. 在 EA 参数中保留剥头皮 SL=350、TP=500，趋势 SL=500。
2. 确认账户为对冲账户，并启用自动交易。
3. 将新编译的 EA 重新加载到测试图表。
4. 打开“工具箱 → 专家”，测试期间观察 `[Protection]` 日志。
5. 测试只使用小手数模拟账户；每完成一个异常场景先确认没有残余仓位和挂单。

## 2. 基础保护测试

### T5-01 剥头皮市价单

1. 点击剥头皮做多。
2. 在“交易”页查看该持仓的止损和止盈。
3. 平仓后再测试做空。

通过标准：多空仓位成交后均立即具有服务器 SL 和 TP；面板保持“就绪”，专家日志没有持续保护异常。

### T5-02 趋势市价单

分别建立趋势多单和空单。

通过标准：服务器 SL 存在，TP 为空；没有出现先裸仓再补 SL 的过程。

### T5-03 限价挂单

分别创建一张剥头皮限价单和一张趋势限价单，在“交易”页检查订单字段。

通过标准：剥头皮挂单带 SL/TP，趋势挂单带 SL；取消挂单后面板恢复正常。

## 3. 外部修改测试

### T5-04 删除策略仓位 SL

1. 建立一张剥头皮或趋势仓位。
2. 在 MT5 中手工将该仓位 SL 删除。
3. 观察 1 至 3 秒。

通过标准：EA 暂时禁开并显示“服务器保护异常”；自动恢复不弱于初始线的 SL，确认后恢复开仓。

### T5-05 放宽与收紧 SL

1. 手工把 SL 调得更靠近亏损方向。
2. 确认 EA 自动恢复最低保护。
3. 再手工把 SL 调得更靠近盈利方向。

通过标准：放宽会被纠正；收紧被接受并记忆，后续刷新、重启和 TP 修复都不会把它放宽。

### T5-06 删除剥头皮 TP

在尚未进入峰值追踪的剥头皮仓位上手工删除 TP。

通过标准：EA 自动补回 TP，且已有更优 SL 保持不变。

### T5-07 不安全挂单

手工删除 TradeEZ 限价挂单的 SL；若券商允许修改，观察 EA 的自动修复。

通过标准：挂单 SL 被恢复；无法恢复时约 8 秒后挂单被撤销，期间不允许新增风险。

## 4. 操作约束测试

### T5-08 撤止盈保护门槛

在服务器 SL 正常时测试“撤止盈”；再通过制造保护异常观察按钮行为。

通过标准：仅在 SL 已确认时允许撤 TP；SL 未确认时拒绝并提示。

### T5-09 参数错误

将任一策略 SL 设置为 0 后重新加载 EA。

通过标准：初始化被拒绝并记录参数错误，不允许产生裸仓。测试后恢复合法参数。

### T5-10 净额账户

仅在可用的净额模拟账户测试。

通过标准：EA 明确提示当前版本仅支持对冲账户，禁止新增交易，但不冒充完整支持。

## 5. 断线与重启测试

1. 建立一张带 SL 的测试仓位和一张带 SL 的测试挂单。
2. 记录服务器显示的 SL/TP。
3. 关闭 EA 或 MT5，再重新打开。
4. 重启后检查 SL/TP 和面板状态。

通过标准：离线期间服务器 SL/TP 仍存在；重启先审计保护再开放新交易；更优 SL 不被放宽。动态追踪在离线期间不作继续运行承诺。

## 6. 日志判断

- 正常确认：不持续出现保护异常，面板允许开仓。
- 修复开始：`[Protection] 检测到保护缺失`。
- 修复复核：`[Protection] 修复复核 ... confirmed=true`。
- 安全退出：`[Protection] 安全退出`。
- 挂单撤销：`[Protection] 不安全挂单撤销`。

若发生失败，请保留专家日志中从首次 `[Protection]` 到最终结果的完整区段，并记录 ticket、实际 SL/TP、测试时间和当时是否休市。
