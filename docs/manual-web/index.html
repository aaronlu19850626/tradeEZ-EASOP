01 / 先读这页

先学会核对，再开始交易

TradeEZ 是 MT5 上的半自动交易面板：你决定买卖方向和时机，EA 帮你执行和管理。它不会自动判断哪里该买、哪里该卖。

第一次使用，请先在模拟账户练习。

不要照抄截图里的手数。截图是当时的模拟账户状态，不是收益展示，也不是推荐配置。

01

先确认对象

账户对不对？图表是不是要交易的黄金品种？有没有其他 EA 在管理同一账户？

02

再确认风险

看清手数、初始止损和持仓上限。按钮亮着不代表一定能成交，也不代表风险已经受控。

03

最后确认结果

点击后到 MT5 底部“交易”页核实持仓、挂单和 SL/TP。别只看按钮或提示文字。

四个必须记住的边界

  • 一键全平不是只平本 EA：它处理当前图表品种的全部持仓和挂单，包括手动单和其他 EA 单。
  • 同步会暂停本 EA 的动态处理：移动止损、主动平仓等可能延后；已被服务器接受的固定 SL/TP 仍由服务器处理。
  • 重置不是恢复本金：它重设统计基线、清除部分限制，不会撤销真实亏损。
  • 平仓请求提交不等于成交：务必确认是否仍有残余仓位或挂单。

本手册是软件操作说明，不提供买卖建议或收益保证。当前实现的技术限制见末尾“已知边界”。

02 / 安装与准备

第一次安装，按这个顺序来

  1. 找到 MT5 的数据目录

    打开 MT5 → 左上角“文件”→“打开数据文件夹”。进入 MQL5 / Experts，建议新建 Gold SOP 文件夹。

  2. 复制编译文件

    将 tradeEZ.ex5 放进去。Logo 已内嵌，不需要另装图片。不要误用其他目录的同名旧版本。

  3. 找到 EA 并加载

    回到 MT5，按 Ctrl+N 打开“导航”，在“EA交易”列表中刷新，找到对应目录的 tradeEZ，将它拖到实际交易品种的图表。

  4. 认真检查输入参数

    先检查两套策略手数、最大持仓、止损止盈、风控额度、交易时间和同步开关。参数不清楚时先取消，不要带着疑问直接运行。

  5. 确认允许交易

    检查 MT5 的算法交易开关及 EA 自身交易权限。打开权限意味着 EA 可以执行交易，请只在确认参数后操作。

  6. 检查底部“交易”页

    按 Ctrl+T 打开工具箱。“交易”页看当前仓位与挂单；“历史”看成交；“专家”和“日志”用于排查错误。

账户类型：当前双策略逐票管理应先在对冲账户（Hedging）验证。净额账户会合并同品种持仓，不能直接假定兼容。建议同一账户只运行一个管理实例，避免状态相互覆盖。

两个权限不要混淆

功能需要什么
打开官网当前实现通过 Windows 调用外部浏览器，需要允许 DLL 导入；只给可信 EA 开启。
同步复盘数据开启同步、填写 API 地址和密钥，并在 MT5 的 EA 选项中配置 WebRequest 地址白名单。DLL 权限不能代替白名单。
03 / 认识面板

从上到下，读懂你的交易台

① 顶栏与报价

Logo、标题或版本号可打开更新日志。LANG 切换语言，< 缩小面板。时钟显示北京时间，“收线”是当前周期 K 线剩余时间。

左边是 Bid（卖价），右边是 Ask（买价）；中间数字为点差。上涨为蓝色，否则为红色，颜色不是开仓信号。

② 账户与风控

左卡看余额、净值、盈亏和重置；右卡看风险状态、周目标和平仓入口。余额和净值是全账户，部分盈亏统计实际仅针对当前品种。

③ 两套策略

左侧剥头皮、右侧趋势。先看右上角手数，再看运行状态和持仓数，最后才操作做空、做多或挂单。

④ 执行参数

底部说明跟随当前加载的参数变化。它方便核对，不代表服务器已接受所有止损设置，成交后仍要查交易页。

看到的状态该怎么理解
就绪（可开仓）当前门控允许尝试开仓，不保证下单成功。
满仓 / 休市 / 非时段已达持仓上限或暂时不允许新增交易。
连亏熔断 / 策略熔断先检查原因。不要为了继续交易而习惯性点重置。
正在同步 / 同步空闲网络活动提示；空闲不等于同步成功，结果需看专家日志。

黄色按钮强调操作重要性，不表示安全或建议点击。策略禁用时相关按钮会变暗。

04 / 做多、做空与挂单

一次点击之后，一定要核对

市价单：现在就尝试成交

  1. 选策略、看手数

    “做多”买入，“做空”卖出。两张卡片使用各自的手数与管理规则。

  2. 单次点击

    网络慢时不要连续点。软件有短时防重复机制，但不能把它当成反复点击的保护保证。

  3. 在交易页确认

    核对品种、方向、手数、成交价及止损/止盈。没有持仓时先查“专家”日志，不要盲目重试。

手数越大，价格波动对应的金额风险通常越大。

本 EA 使用配置手数，并不会根据你的可承受亏损自动计算合适手数。

限价单：等到指定价格再尝试成交

操作价格要求 / 计算
输入价格 → 限价多低于当前 Ask，并满足券商最小距离。
输入价格 → 限价空高于当前 Bid，并满足券商最小距离。
+2空 / +3空 / +5空以当前 Bid 加 2.00 / 3.00 / 5.00 挂空。
−2多 / −3多 / −5多以当前 Ask 减 2.00 / 3.00 / 5.00 挂多。

例如 Ask=2400.00，点击“−2多”会尝试在 2398.00 挂限价多单。这里的 2 是价格差 2.00，不是“2 个标准点”。挂单通常持续有效，直到成交或撤销。

现有持仓上限不预留挂单名额。多笔挂单同时成交可能超出上限；普通熔断也不会自动撤掉所有已有挂单。
05 / 平仓与按钮范围

先认清“平谁”，再按按钮

按钮处理范围会撤挂单吗
一键全平当前品种全部持仓，含手动和其他 EA会，当前品种全部挂单
平剥头皮当前品种、剥头皮魔术号的持仓不会
平趋势单当前品种、趋势魔术号的持仓不会
平盈利单当前品种利润+隔夜费大于 0 的持仓，含手动及其他 EA不会

“魔术号”是 EA 给交易使用的策略识别编号，不是密码。它帮助区分由哪套策略管理。

批量提交 ≠ 同时全部成交。

当前批量平仓不逐单等成交，但服务器仍分别处理请求。平仓后必须检查交易页；拒单、部分成交或断线可能留下仓位。盈利过滤也不保证扣除所有费用后净盈利。

剥头皮卡片的两个特殊按钮

改趋势
当前实现主要撤去符合条件持仓的 TP、保留 SL，并登记内部标记。并没有真正切换到趋势卡片的阶梯管理，统计与策略平仓归属仍是剥头皮。
撤止盈
撤去已进入剥头皮追踪名单的持仓 TP，保留 SL。没有符合条件持仓或处于风控禁用状态时，不一定能执行。
06 / 止损与策略规则

固定保护与动态保护，不是一回事

服务器固定保护

SL=止损，TP=止盈。以券商实际接受的价格为准。EA 暂停时，已经提交成功的固定保护仍由服务器处理，但成交价格可能受行情影响。

EA 动态管理

移动止损、追踪回撤、减仓与超时平仓都需要 EA 继续运行。断网、关闭终端、同步或模态确认可能使处理延迟。

源码默认值，仅用于读懂规则

策略初始保护后续管理
剥头皮SL 350 点 / TP 500 点浮盈约达 300 点启动追踪，峰值回撤参数 150 点；超时强平默认关闭。
趋势SL 500 点，无固定 TP+300 尝试保本；+500 锁 200；+800 锁 500 并减仓 50%；+1000 进入 350 点追踪。

1 标准点 = 0.01 价格单位。350 点就是价格差 3.50。截图里可能加载了不同参数，始终以 EA 属性和底部“策略执行参数”为准。

“保本”通常指 SL 移到开仓价，不包含全部手续费、隔夜费和滑点。实际减仓量还受最小手数与步长影响。

当前版本需要特别留意：

剥头皮跌回追踪启动线以下、趋势跳过减仓档位或跌回追踪线以下时，代码存在跳过部分动态判断的路径。不要将本地追踪当作已验证的无条件保护；请先模拟验证，并核查服务器 SL。

07 / 风控与重置

风控提示出现时，先停下来

普通亏损额度：通常是禁开，不是全平

源码默认日额度 500，剥头皮占 70%=350，趋势占 30%=150。按对应范围已实现盈亏加浮动盈亏判断。达到限额主要阻止新增开仓，不等于自动清掉所有持仓或挂单。

连亏冷却：给交易留一个暂停键

默认连续 3 笔亏损触发 10 分钟冷却。统计的是平仓成交，部分平仓也可能计数。先检查“系统安全状态”和冷却提示，不要急着解除。

利润护城河：从盈利高点看回撤

内部高点包含浮盈，可能与卡片“今日最高盈利”的已实现口径不同。达到保护条件并出现规定回撤时会发起当前品种全平与撤单。

有一个容易误读的默认值：

第一档回撤比例默认是 300%，不是 30%。名为“清盘触发”的盈利阈值达到时，当前代码主要锁定新开仓；真正全平还依赖回撤条件。配置前应明确规则，不要只凭参数名称理解。

“重置”到底改变什么？

会改变不会改变
重新设置统计起点和余额基准；清除相关高点、连亏计数、冷却与风控锁定不会平仓或撤挂单；不会改已有 SL/TP；不会删除券商成交历史；不会消除实际亏损

开启“显示重置按钮”配置后，按钮在账户卡片倒计时左侧。点击会出现确认窗口；不确定时选择“否”。已有浮亏仍可能在下一次检查中再次触发风控。

确认窗口等待期间，本 EA 的事件处理也会暂停。请及时选择，不要在有持仓时长时间挂着确认框。手动重置不会清零本周历史统计，也不会自动完整同步。

08 / 同步复盘数据

最好在空仓时，把记录送到复盘系统

  1. 先配置，再操作

    开启 Inp_EnableSync，填写可信 HTTPS API 地址与账户密钥，配置 WebRequest 白名单。同步为 false 时按钮隐藏，这是正常现象。

  2. 检查全账户与挂单

    优先在全账户空仓时操作；只看当前图表空仓不够。挂单也可能在同步途中成交。

  3. 点击“同步数据”并阅读确认

    确认后会依次同步品种、成交、账户快照、EA 参数和心跳。没有准备好就选择“否”。

  4. 看顶栏，再核对结果

    红色“正在同步”表示请求活动；最新界面不再显示遮罩。请求很快时提示会短暂保留。回到“同步空闲”后，仍要核对专家日志与复盘系统。

方式有持仓时会不会同步
定时自动全账户有持仓则延后，还需界面空闲约 5 秒且未编辑价格。
手动确认会，确认后允许有持仓同步。
每日初始化会，按统计日尝试一次；首次挂载也可能补做。
取消遮罩并没有消除阻塞。

网络请求等待期间，本 EA 的动态风控和界面事件可能延后。单次超时参数不代表整轮同步的总耗时上限。

成交同步可能上传全账户符合条件的记录，不限当前品种。不要把账户密钥、含密钥的参数截图或预设文件公开。同步失败请查日志，不要反复点击。

09 / 缩小模式

留住操作空间，不停止后台管理

仍可直接操作

做多、做空、改趋势、撤止盈、±2/3/5 快捷挂单，以及底部一键全平和平盈利单。

需要展开再操作

输入具体挂单价、策略分类平仓、手动同步、重置以及账户和风控明细。

缩小后后台风控继续运行。但超时强平倒计时等侧板未必显示，请不要把“没看见提示”理解成“规则关闭了”。

10 / 统计与周目标

看结果，也要看统计口径

三种查看方式

  • 点“日统计”：看净盈亏、胜率、平均持仓时间与策略分类。
  • 点“今日实现盈亏”或策略胜负数字：看平仓明细。虽然去掉了“[点击]”，仍然可以点击。
  • 到 MT5 的“历史”页：核对真实成交、手续费和分批平仓。EA 统计不能代替券商账单。
常见词白话解释
余额未将当前未平仓浮动盈亏计入的账户余额。
净值账户当前权益，随持仓盈亏变化。
已实现盈亏已平仓部分的统计结果。
浮动盈亏仍在持仓、尚未确定的结果。
胜率统计范围内盈利成交占比；高胜率不必然盈利。

周目标是自然周吗？是。

按北京时间周一 00:00起算，仅统计当前品种本周平仓成交，包括手动和其他 EA。未平仓浮盈不计入；上周开仓、本周平仓的成交计本周。默认目标 4000，达到后显示已完成，不会因此自动平仓。

日统计默认在北京时间 04:50 切换统计日，手动重置会改变日基线。部分平仓可按多笔成交计算；开仓手续费可能未完整纳入。明细最多 30 行，没有分页。看到差异时先核对区间和费用。

11 / 遇到问题怎么办

先定位，再操作

按钮亮着，为什么下不了单？

检查算法交易权限、休市/交易时段、持仓上限、账户可用资金及价格距离；查看“专家”日志中的拒绝原因。不要连续点击试错。

点击全平，为什么还有单？

请求可能被拒绝、部分成交或断线，也可能是其他品种的持仓。核对交易页的品种和挂单，保留日志后再判断下一步，不要只相信“已提交”。

同步按钮不见了？

检查同步开关是否为 false，以及是否处于缩小模式。展开后仍没有，核对实际加载的 EX5 版本和目录。

有持仓时为什么仍同步？

手动确认和每日初始化是明确例外；也可能在请求发起后新产生了持仓。取消遮罩不会让请求变成后台异步。

改趋势后，为什么仍算剥头皮？

当前版本没有真正更换策略归属，主要是撤 TP 并保留原 SL。不要按名字误以为已启用趋势阶梯规则。

升级了，界面还是旧的？

确认复制的是最新 tradeEZ.ex5，而非源码；检查是否加载了其他目录的同名文件。先妥善处理持仓管理，再重新加载。版本号 v1.03 不会随每次修补变化。

鼠标没有变成手型，是坏了吗？

不是。当前自定义手型路径为避免闪烁已停用；判断可点击区域请看本手册，不要只看光标。

最值得优先核对的已知边界有哪些？

追踪激活后回落的分支、跨档跳价时减仓、异步平仓残仓、第一档护城河 300% 默认值、多实例状态互相覆盖、日报跨日区间及同步历史完整性均需验证。不要在未理解和测试的情况下依赖它们作为唯一风险保护。
