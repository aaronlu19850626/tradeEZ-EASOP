## 一、系统概述

### 1.1 系统目标

开发一款基于《现货黄金交易体系 SOP》的自动化辅助交易EA，核心功能包括：
- 手数识别订单类型（剥头皮/趋势单）
- 分策略移动止损管理
- **可配置日回撤额度，自动按比例分配策略熔断阈值**
- 利润护城河保护
- 可视化信息面板与一键操作

### 1.2 核心设计原则

```
┌─────────────────────────────────────────────────────────────┐
│                      设计原则                                │
├─────────────────────────────────────────────────────────────┤
│ 1. 手数决定策略：0.5手=剥头皮，0.3手=趋势单                    │
│ 2. 策略隔离：两类策略独立风控，互不影响                         │
│ 3. 持仓限制：每类策略同时只允许持有1单                          │
│ 4. 比例联动：日回撤额度变化时，策略熔断按固定比例自动调整        │
│ 5. 参数可配：所有关键参数均可通过输入参数调整                    │
│ 6. 安全优先：严格执行熔断机制，保护账户安全                      │
└─────────────────────────────────────────────────────────────┘
```

## 二、目标与回撤体系（新增）

### 2.1 周度目标体系

根据SOP文档，周度盈利目标会影响次日风控参数：

| 周累计盈利 | 次日回撤阈值调整 |
|------------|------------------|
| 基础状态 | 日回撤 = 用户设定值（默认$500） |
| +$1,000 | 日回撤缩减至 $300 |
| +$1,500 | 日回撤缩减至 $200 |
| +$2,000+ | 最低交易频率/考虑休息 |

### 2.2 日回撤额度与策略熔断比例联动

**核心机制：用户只需设置【日最大回撤】，系统自动按比例分配各策略熔断阈值**

#### 默认比例配置（可自定义）

| 策略 | 占比 | 说明 |
|------|------|------|
| 剥头皮 | **60%** | 高频策略，分配更多额度 |
| 趋势单 | **40%** | 低频策略，分配较少额度 |
| **合计** | **100%** | 不超过日最大回撤 |

#### 示例计算

| 日最大回撤设定 | 剥头皮熔断 (60%) | 趋势熔断 (40%) |
|----------------|------------------|----------------|
| $500 | $300 | $200 |
| $400 | $240 | $160 |
| $300 | $180 | $120 |
| $200 | $120 | $80 |

### 2.3 联动计算流程图

```
用户设置日回撤额度
        │
        ▼
┌─────────────────────────────────────────┐
│ Inp_DailyMaxDrawdown = $500 (用户输入)    │
└────────────────┬────────────────────────┘
                 │
        ┌────────┴────────┐
        ▼                 ▼
┌───────────────┐  ┌───────────────┐
│ 剥头皮熔断     │  │ 趋势熔断       │
│ = $500 × 60%  │  │ = $500 × 40%  │
│ = $300        │  │ = $200        │
└───────────────┘  └───────────────┘

当周盈利达$1000，用户调整日回撤至$300:
        │
        ▼
┌───────────────┐  ┌───────────────┐
│ 剥头皮熔断     │  │ 趋势熔断       │
│ = $300 × 60%  │  │ = $300 × 40%  │
│ = $180        │  │ = $120        │
└───────────────┘  └───────────────┘
```

## 五、移动止损机制

### 5.1 剥头皮移动止损

**规则：简单保本机制**

| 触发条件 | 执行动作 | 锁定利润 |
|----------|----------|----------|
| 浮盈 ≥ $1.5 | 止损移至盈利 $0.5 位置 | $0.5 |

**计算公式：**
```
Buy单新止损 = 开仓价 + 0.5美金对应点数
Sell单新止损 = 开仓价 - 0.5美金对应点数
```

### 5.2 趋势单移动止损（阶梯式）

**规则：按照SOP文档的防守反击法**

| 浮盈状态 | 止损调整 | 锁定净利润 | 特殊动作 |
|----------|----------|------------|----------|
| 达到 +3点 ($90) | 移至成本价 | $0 | 无 |
| 达到 +5点 ($150) | 移至 +2点位置 | $60 | 无 |
| 达到 +8点 ($240) | 移至 +5点位置 | $150 | 无 |
| 达到 +10点 ($300) | 移至 +7点位置 | $210 | **减仓50%** |
| 减仓后继续 | 止损保持+7点 | $210 | 目标看15点 |

### 5.3 趋势单减仓机制详解

```
减仓流程（达到+10点时触发）:
     │
     ▼
┌─────────────────────────────────────┐
│ 1. 平仓50%仓位（0.3手→0.15手）        │
│    - 锁定利润: 0.15手 × 10点 = $150   │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│ 2. 剩余0.15手止损移至+7点             │
│    - 保底利润: 0.15手 × 7点 = $105    │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│ 3. 剩余仓位目标看15点                 │
│    - 潜在利润: 0.15手 × 15点 = $225   │
└─────────────────────────────────────┘

总收益构成:
已平仓: $150 (确定)
持仓中: $105 ~ $225 (保底~目标)
总计: $255 ~ $375
```

## 六、风险控制框架（更新）

### 6.1 熔断额度计算公式

```
剥头皮熔断额度 = Inp_DailyMaxDrawdown × (Inp_ScalpDrawdownRatio / 100)
趋势单熔断额度 = Inp_DailyMaxDrawdown × (Inp_TrendDrawdownRatio / 100)
```

### 6.2 分级熔断机制（更新）

| 级别 | 触发条件 | 执行动作 | 自动恢复 |
|------|----------|----------|----------|
| **Level 1** | 连续N笔止损 | 弹窗警告，建议冷却15分钟 | 手动确认 |
| **Level 2** | 剥头皮亏损达**日回撤×60%** | 冻结剥头皮策略 | 次日重置 |
| **Level 3** | 趋势单亏损达**日回撤×40%** | 冻结趋势策略 | 次日重置 |
| **Level 4** | 总亏损达**日回撤100%** | 全局熔断，禁止所有操作 | 次日重置 |

### 6.3 熔断额度示例表

| 日最大回撤 | 剥头皮熔断(60%) | 趋势熔断(40%) | 全局熔断(100%) |
|------------|-----------------|---------------|----------------|
| $500 | $300 | $200 | $500 |
| $400 | $240 | $160 | $400 |
| $300 | $180 | $120 | $300 |
| $200 | $120 | $80 | $200 |

### 6.4 止损次数熔断

| 策略 | 日内止损次数上限 | 触发动作 |
|------|------------------|----------|
| 剥头皮 | 3次 | 当日冻结剥头皮 |
| 趋势单 | 2次 | 当日冻结趋势单 |

### 6.5 风控可配置参数（更新）

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| **核心回撤参数** | | |
| `Inp_DailyMaxDrawdown` | 500.0 | **日最大回撤额度（美金）** |
| `Inp_ScalpDrawdownRatio` | 60.0 | 剥头皮占比（%） |
| `Inp_TrendDrawdownRatio` | 40.0 | 趋势占比（%） |

| 趋势单剩余止损 | `上限 - 已止损次数` | <50%黄, =0红 |
| 总熔断额度 | `日回撤` | 固定显示 |

| 总距熔断 | `总额度 - 总已亏损` | <30%绿, 30-60%黄, >60%红 |

## 十六、文档确认清单

- [x] **订单识别**：仅通过手数识别（0.5手=剥头皮，0.3手=趋势），不使用Magic Number
- [x] **非系统订单**：其他手数订单完全忽略，不做任何处理
- [x] **持仓限制**：剥头皮和趋势各最多1单
- [x] **剥头皮移动止损**：浮盈$1.5触发，锁定$0.5
- [x] **趋势移动止损**：阶梯式（3点→成本价，5点→+2点，8点→+5点，10点→减仓50%+锁+7点）
- [x] **日回撤联动**：用户设日回撤，剥头皮60%、趋势40%自动计算
- [x] **面板显示**：今日盈利目标、净盈亏、熔断距离（金额+止损次数）
- [x] **一键按钮**：剥头皮Buy/Sell、趋势Buy/Sell、平仓按钮
