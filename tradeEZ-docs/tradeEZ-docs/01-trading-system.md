# 黄金日内交易系统与风险管理

> 归档日期：2026-09-10。来源：原会话《黄金行情监控》。本文是会话资料整理，方案与参数仍属草案；所有案例数值均为教学或产品示例，非已验证业绩。

整理原会话的两类交易模型、周期分工、仓位和复盘原则。风险参数仅保留为历史讨论示例，不作为平台默认值。

## 核心流程

市场环境 → 关键位置 → 价格行为确认 → 可选订单流确认 → 入场 → 结构失效点 → 风险收益评估。

只先研究两类 Setup：

| 模型 | 条件链 | 失效参考 |
|---|---|---|
| Trend Pullback | 趋势明确 → 突破 → 回踩 → 小周期确认 | 回踩结构失效 |
| Liquidity Sweep | 关键高低点 → 扫过后回区间 → CHOCH → 回测确认 | 扫单极值之外 |

## 周期分工

| 周期 | 用途 |
|---|---|
| 1H | 市场环境：趋势、震荡、消息驱动 |
| 15M | 日内方向和重要结构 |
| 3M / 5M | 突破、回踩、Sweep 等结构 |
| 1M | 入场触发与失效点细化 |

位置包括 PDH/PDL、Asia High/Low、London High/Low、Daily Open、周高低点、整数位；VWAP、EMA 为辅助。DXY、美债与宏观事件用于记录环境。

## 原会话中的风险参数示例

| 参数 | 历史讨论值 |
|---|---|
| 普通机会单笔风险 | 账户的 1% |
| A+ 机会单笔风险 | 1.5%–2% |
| 当日亏损上限 | 3% |
| 连续亏损 | 2 笔后停止 |
| 每日交易数量 | 不超过 4 笔 |
| 计划盈亏比 | 至少 2R，优质机会讨论 3–5R |
| 复盘批次 | 每 30 笔 |

这些数值不是用户最终确认的风控政策。蓝图另出现 1.5% 及单位不明的“1.5R Account Risk”，需在实现前统一。交易时段按伦敦、纽约会话定义；不要硬编码原会话中的北京时间，需处理夏令时。

## 仓位计算示例

```text
允许亏损金额 = 账户权益 × 单笔风险比例
手数 = 允许亏损金额 / (止损价格距离 × 每手每单位价格变动价值)
```

原例：账户 10,000 美元，风险预算 150 美元，止损距离 6 美元；假设每手价格变动 1 美元对应 100 美元盈亏，则手数 0.25。合约规格、费用、点差与滑点会影响实际风险，平台需读取账户对应规格，不能对所有经纪商写死。

## 持仓管理与复盘

- 原讨论只允许在盈利且结构继续确认时考虑加仓，不允许亏损摊平；加仓后的合计风险尚未定义。
- 分批止盈示例：1.5R 平 20%，2R 平 30%，剩余 50% 跟踪趋势。并非固定默认策略。
- 记录初始风险与实际盈亏，避免仅按最后一笔平仓价格计算整笔收益。
- 复盘 Setup、时段、R、MAE/MFE、执行错误，不因两三笔结果临时改系统。
- 重点错误：追单、提前入场、无确认、扩大止损、超仓、报复交易、过度交易。

## 概率框架

```text
期望值 = 胜率 × 平均盈利R − 亏损率 × 平均亏损R绝对值
```

教学例：40% 胜率、平均盈利 3R、平均亏损 1R，期望值为 +0.6R。正期望必须通过真实数据检验，不能由形态名称或高盈亏比直接推断。
