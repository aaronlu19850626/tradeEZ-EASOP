# 入场模型、确认规则与交易术语

> 归档日期：2026-09-10。来源：原会话《黄金行情监控》。本文是会话资料整理，方案与参数仍属草案；所有案例数值均为教学或产品示例，非已验证业绩。

保留原会话较完整的入场教学材料。以下价格用于解释结构；BOS/CHOCH 等判定规则还需在 Playbook 中量化。

可以。下面把前面提到的“入场点位”和“入场形态”拆成一套可以真正拿去看盘执行的规则。重点不是告诉你某个固定价格一定买或卖，而是定义：**价格走到什么位置、出现什么结构、满足什么确认后才允许入场。**

对于黄金这种高波动品种，尤其你还是日内、偏激进风格，我建议把入场逻辑固定成两大类：**趋势回踩入场**和**流动性扫单反转入场**。其他形态暂时不做，先把这两个练熟。

---

# 一、先理解：“入场点位”不是一个价格，而是一个区域

很多人看黄金会问：

> 4420能不能做多？  
> 4450能不能做空？

这种思维很危险。

专业一些的理解应该是：

> **为什么4420值得做多？价格到4420之前发生了什么？4420附近有没有结构支持？如果判断错误，什么位置证明我错了？**

所以一个完整的入场至少有四层。

| 层级 | 要回答的问题 |
|---|---|
| 市场环境 | 今天偏趋势还是震荡？ |
| 关键位置 | 价格现在到了哪里？ |
| 入场形态 | 这个位置出现了什么行为？ |
| 触发信号 | 到底什么时候按下买入/卖出？ |

例如：

```text
前高
4450 ──────────────

            价格突破
               ↑
              4456
               │
               ↓
4450 ─────── 回踩 ──────
             ↑
            4452 买入

止损 4445
目标 4466 / 4475
```

真正的入场逻辑不是：

**“4452做多。”**

而是：

**“4450原来是压力 → 被有效突破 → 回踩4450附近没有跌回去 → 形成新的短周期多头结构 → 4452附近寻找入场。”**

这两者差别非常大。

# 二、什么叫“市场结构”

这是你以后交易黄金最重要的概念之一。

市场无非三种状态：

**上涨、下跌、震荡。**

判断趋势，不需要复杂指标，首先看高点和低点。

### 上涨结构

```text
          HH
          /\
         /  \
    HL  /    \
     \ /      \
      V        \       HH
                \     /\
                 \   /  \
                  HL
```

其中：

**HH = Higher High，创新高。**

意思是：

> 后一个高点高于前一个高点。

**HL = Higher Low，抬高的低点。**

意思是：

> 后一个回调低点高于前一个低点。

因此：

```text
HH + HL + HH + HL
```

通常代表多头结构。

---

### 下跌结构

```text
       LH
       /\
      /  \
     /    \
    /      LL
   /
 LH
```

对应：

**LH = Lower High，降低的高点。**

**LL = Lower Low，创新低。**

所以：

```text
LL + LH + LL + LH
```

代表空头结构。

---

# 三、什么叫 BOS

**BOS = Break of Structure**

中文一般叫：

> **结构突破。**

这是判断趋势延续非常重要的信号。

例如：

```text
前高
4430 ─────────

       /\ 
      /  \
4420 /    \
    /      \
              ↑
              │
4430 ─────────│
              │ BOS
              │
             4438
```

如果价格真正突破前高4430：

可以理解为：

> 原来的多头结构继续成立。

这里的重点是：

**真正突破。**

不是价格瞬间刺一下4430。

例如：

```text
最高4433
   |
   |
4430 ─────────
   |
   ↓
4422
```

这种很可能只是：

**假突破。**

所以日内黄金中，我更重视：

**5分钟K线实体收盘突破。**

例如压力位4430：

不理想：

```text
最高价4435
收盘价4428
```

比较理想：

```text
最高价4437
收盘价4434
```

第二种才更接近有效突破。

---

# 四、什么叫 CHOCH

**CHOCH = Change of Character**

中文常翻译：

> **结构性格改变 / 市场结构转变。**

简单理解就是：

> 原来的趋势可能正在发生改变。

例如之前一直上涨：

```text
4400
  ↓
4420 HH
  ↓
4410 HL
  ↓
4435 HH
  ↓
4425 HL
```

正常情况下：

4425不应该被明显跌破。

如果突然：

```text
4425
 ↓
4418
 ↓
4410
```

那么上涨结构第一次出现破坏。

这就是一种：

**CHOCH。**

它不是百分百反转，但告诉你：

> 不要再无脑做多。

对于我们后面讲的“假突破反杀”，CHOCH非常重要。

---

# 五、第一种核心形态：Trend Pullback

中文：

# 趋势突破回踩

这是我最推荐你作为主系统的形态。

完整结构是：

```text
趋势
↓
关键位
↓
突破
↓
回踩
↓
确认
↓
入场
```

不是：

```text
看到大阳线
↓
追
```

---

# 六、Trend Pullback具体怎么做

假设黄金当前上涨。

15分钟图：

```text
4400
 ↑
4418
 ↓
4408
 ↑
4430
```

4430是前高。

随后：

```text
4430被突破
↓
4438
```

这个时候不要直接追。

等待：

```text
4438
↓
4433
↓
4431
```

价格回到4430附近。

这里就是：

# Potential Entry Zone

也就是：

**潜在入场区域。**

---

# 七、为什么“回踩”很重要

因为4430之前是什么？

**阻力位。**

突破之后，它有可能发生：

### Resistance → Support

即：

> 原来的阻力变成支撑。

这叫：

**Support / Resistance Flip**

简称：

**S/R Flip。**

示意：

```text
突破前：

4430 ─────── 阻力
      ↑
价格上不去

突破后：

        4440
          ↑
4430 ─────── 支撑
          ↑
        回踩
```

这类位置的风险收益比通常比追突破好。

---

# 八、回踩以后不能立刻买

这是一个非常重要的区别。

很多人看到：

```text
4430支撑
```

价格一碰4430就买。

不够。

需要：

# Trigger

也就是：

**触发信号。**

你的1分钟或3分钟图要重新形成多头。

例如：

```text
4438
 ↓
4430
 ↑
4434
 ↓
4431
 ↑
4436
```

你会发现：

```text
4430
↓
4434
↓
4431
```

4431没有创新低。

然后：

```text
4436 > 4434
```

形成一个微型：

```text
HL
+
BOS
```

这才是比较好的多头Trigger。

---

# 九、真正精细的入场过程

例如：

15M关键位：

```text
4430
```

突破：

```text
4438
```

回踩：

```text
4431
```

1M形成：

```text
4431
↑
4435
↓
4432
↑
4436
```

那么你的Trigger就是：

**突破4435。**

于是可以理解为：

```text
Entry：4435~4436
SL：4429附近
```

为什么止损在4429？

因为：

如果价格重新跌破4430，而且明显跌回原来的区间：

说明：

> **突破失败。**

你的交易逻辑就失效了。

这叫：

# Invalidation

中文：

> **交易逻辑失效点。**

止损应该放在：

**逻辑失效的位置。**

而不是：

> “我只想亏100美元，所以随便放一个止损。”

# 十、一个完整Trend Pullback案例

假设：

```text
前高：4420
```

市场突破：

```text
4420
↓
4432
```

随后回踩：

```text
4432
↓
4422
```

1分钟结构：

```text
4422
↑
4427
↓
4424
↑
4429
```

那么：

```text
4427
```

这个小高点被突破。

形成短周期BOS。

可以考虑：

```text
Entry：4428~4429

SL：4419

风险：
约 $9~10
```

如果风险是：

```text
1R = $10
```

目标：

```text
TP1 = 4448
约 +2R

TP2 = 4458
约 +3R

Runner
继续跟随
```

这里的：

# Runner

意思是：

> 留下一部分仓位，不固定止盈，让它跟随趋势。

很多5R、8R甚至10R交易就是Runner产生的。

# 十一、第二种核心入场：Liquidity Sweep

这一套非常适合黄金。

中文可以理解成：

# 流动性扫单 / 扫止损

先理解“流动性”。

交易市场里大量止损会集中在一些非常明显的位置。

例如：

```text
昨日高点
4450
```

很多空单交易者止损可能在：

```text
4452
4455
4460
```

同时很多突破交易者会设置：

```text
突破4450买入
```

所以4450上方往往存在大量订单。

这就形成了：

# Liquidity Pool

即：

> **流动性池。**

---

# 十二、为什么黄金经常突然突破前高又暴跌

例如：

```text
Previous Day High
4450 ─────────────

价格
4440
↑
4448
↑
4452
↑
4458
```

大量：

```text
空单止损
+
突破买单
```

都被触发。

然后价格突然：

```text
4458
↓
4451
↓
4446
↓
4435
```

这就是非常典型的：

# Liquidity Sweep

或者：

# Stop Hunt

通俗说：

> **扫止损。**

但不要把它神秘化成“庄家故意来扫我”。

更准确的理解是：

> 关键价位附近订单密集，价格穿越该区域后，如果没有持续的真实买盘继续承接，就容易快速反向。

---

# 十三、Liquidity Sweep不能看到长上影就做空

这是很多ICT/SMC初学者最大的错误。

他们看到：

```text
前高4450

最高4458
收盘4448
```

马上：

> Sweep！做空！

不够。

我要求至少看到：

```text
Sweep
+
重新进入区间
+
CHOCH
+
回抽
```

然后再入场。

# 十四、完整的Sweep做空结构

假设：

```text
昨日高点 4450
```

价格：

```text
4445
↑
4452
↑
4458
```

随后：

```text
4458
↓
4449
```

重新跌回4450以下。

第一层确认出现。

然后1M：

```text
4458
↓
4449
↑
4454
↓
4446
```

原本短周期上涨结构：

```text
HH
HL
HH
```

现在开始：

```text
LL
```

形成：

# CHOCH

然后价格反弹：

```text
4446
↑
4451
```

但无法重新回到4458。

这时候：

```text
4450~4452
```

反而是比较好的空单区域。

结构变成：

```text
4458 Sweep
  ↓
4446 CHOCH
  ↑
4451 Pullback
  ↓
Short
```

相比4458直接猜顶：

**4451确认以后再做空，虽然少赚几美元，但胜率通常更高。**

# 十五、什么叫 FVG

你以后看SMC/ICT资料一定会经常遇到：

# FVG = Fair Value Gap

通常翻译：

> 公允价值缺口 / 失衡区。

实际上不用搞得太神秘。

简单理解：

> 某段价格移动得非常快，中间缺乏充分双向成交。

例如三根K线：

```text
K1 high = 4420

K2 巨大阳线

K3 low = 4425
```

那么：

```text
4420~4425
```

之间可能出现FVG。

示意：

```text
4428 ─ K3
     │
4425 │
     │ ← FVG
4420 │
     │
4418 ─ K1
```

很多时候价格之后会回到这个区域。

所以FVG可以成为：

**回踩区域。**

但我不会单独因为FVG就开仓。

应该：

```text
关键结构
+
FVG
+
回踩
+
Trigger
```

才有价值。

---

# 十六、什么叫 Order Block

另一个你一定会遇到的名词：

# OB = Order Block

通常翻译：

> 订单块。

例如强势上涨前最后一根明显阴线。

很多交易体系把它认为是：

> 大资金建仓区域。

我建议你不要过度神化。

从纯交易角度，可以理解成：

> **强烈位移行情启动前最后一个关键整理区。**

例如：

```text
4410
↓
4406  阴线
↓
4405
↑
4415
↑
4430
↑
4450
```

那么4405–4410附近可能被定义为一个Bullish Order Block。

但是对我们这套系统来说：

**OB只是辅助定位，不是入场原因。**

---

# 十七、什么叫 Displacement

非常重要。

# Displacement = 强位移

意思是：

> 价格突然非常有力量地离开某一区域。

比如：

```text
4420
4421
4420
4422

突然

4428
4435
4442
```

这种连续大实体K线就是明显：

**Displacement。**

它说明：

> 市场一边的力量突然占据优势。

所以：

**BOS + Displacement**

比单纯BOS更值得信任。

例如：

低质量突破：

```text
4430
4431
4430
4432
4431
```

高质量突破：

```text
4430
4435
4441
4446
```

后者明显更强。

---

# 十八、什么叫 Retest

# Retest = 回测 / 回踩

突破以后重新测试突破区域。

例如：

```text
阻力4430

突破
↓
4440

回到
↓
4432
```

就是Retest。

你会经常看到：

```text
Breakout
→
Retest
→
Continuation
```

即：

**突破 → 回踩 → 延续。**

这是我们第一套系统的核心。

---

# 十九、什么叫 Fakeout

# Fakeout = 假突破

例如：

```text
压力4450

最高4458
↓
收盘4447
↓
跌到4435
```

表面上突破了4450。

实际上：

没有站稳。

这就是Fakeout。

当Fakeout发生在：

**昨日高低点、亚洲高低点、伦敦高低点、整数位**

附近时尤其值得注意。

# 二十、为什么我要特别看这些价格

对于黄金日内，我会每天画出以下几个位置：

| 名称 | 英文 | 意义 |
|---|---|---|
| 昨日最高 | PDH | Previous Day High |
| 昨日最低 | PDL | Previous Day Low |
| 亚洲盘最高 | Asia High | 亚洲时段高点 |
| 亚洲盘最低 | Asia Low | 亚洲时段低点 |
| 伦敦盘最高 | London High | 欧洲盘重要流动性 |
| 伦敦盘最低 | London Low | 欧洲盘重要流动性 |
| 当日开盘 | Daily Open | 当日多空参考 |
| VWAP | Volume Weighted Average Price | 成交量加权平均价 |

这些地方之所以重要，不是因为它们“神奇”。

而是因为：

> 大量市场参与者都能看到。

所以：

**订单容易聚集。**

---

# 二十一、什么叫 VWAP

# VWAP = Volume Weighted Average Price

中文：

> **成交量加权平均价。**

它可以粗略理解为：

> 今天市场的平均成交成本。

日内交易中：

```text
价格持续 > VWAP
```

通常说明：

市场偏强。

```text
价格持续 < VWAP
```

通常说明：

市场偏弱。

但不要简单：

> 站VWAP做多，跌VWAP做空。

它只是一个：

**Context Filter**

即：

> 市场环境过滤器。

---

# 二十二、什么叫 EMA

# EMA = Exponential Moving Average

指数移动平均线。

例如：

**20 EMA**

表示最近20根K线价格的加权平均，其中最近价格权重更高。

对于5分钟图：

```text
Price > EMA20
EMA20 向上
```

意味着：

短周期通常偏强。

同样只是：

**辅助。**

不是：

```text
碰EMA就做多。
```

---

# 二十三、真正适合你的入场模型

因为你偏激进，我反而不建议你在形态刚出现一点影子就进去。

更适合你的方式是：

> **确认后，用更小周期压缩止损。**

例如15分钟看到趋势。

5分钟看到：

```text
突破 + 回踩
```

然后1分钟寻找：

```text
CHOCH
+
BOS
```

最后用1分钟结构作为止损。

这样你可能得到：

```text
止损 $4
目标 $16
```

也就是：

```text
1:4
```

而不是15分钟直接买：

```text
止损 $15
目标 $20
```

只有：

```text
1:1.3
```

这就是小周期执行最大的意义。

---

# 二十四、理解 R 非常重要

以后我们不要总说：

> 赚了100美元。

要说：

# R

R代表：

> **一次交易愿意承担的初始风险。**

假设：

```text
Entry 4420
SL    4415
```

你的风险距离：

```text
$5
```

那么：

```text
4415 = -1R
4425 = +1R
4430 = +2R
4435 = +3R
4450 = +6R
```

如果账户单笔风险是：

```text
$200
```

那么：

```text
-1R = -$200
+3R = +$600
+6R = +$1200
```

R可以让不同仓位、不同账户规模的交易统一统计。

---

# 二十五、什么是RR

# RR = Risk Reward Ratio

风险收益比。

例如：

```text
风险：$5
目标：$15
```

那么：

```text
RR = 1:3
```

也就是：

> 最多亏1，计划赚3。

对于我们的激进型系统：

我不会追求70%以上胜率。

更重要的是：

```text
平均亏损 ≈ 1R
平均盈利 > 2R
```

---

# 二十六、什么是 MAE / MFE

这是你以后做交易日志非常重要的两个数据。

### MAE

**Maximum Adverse Excursion**

最大不利波动。

例如：

```text
4420买入
最低跌到4417
最后涨到4440
```

MAE：

```text
-$3
```

---

### MFE

**Maximum Favorable Excursion**

最大有利波动。

例如：

```text
4420买入
最高4445
最终4430平仓
```

MFE：

```text
+$25
```

如果你统计100笔以后发现：

```text
平均MAE = 3美元
```

但是你的止损一直放：

```text
10美元
```

就意味着：

你的止损可能过宽。

反过来如果大量盈利交易：

```text
MAE = 6~8美元
```

你却固定：

```text
5美元止损
```

说明止损太紧。

# 二十七、黄金必须理解 Spread 和 Slippage

# Spread

中文：

> 点差。

例如：

```text
Bid：4420.00
Ask：4420.30
```

点差：

```text
$0.30
```

你刚买进去其实立刻就是浮亏。

---

# Slippage

中文：

> 滑点。

你希望：

```text
4415止损
```

但CPI公布时市场瞬间跳：

```text
4415
↓
4410
```

你真正成交：

```text
4410
```

于是计划亏：

```text
-$5
```

实际可能：

```text
-$10
```

这就是为什么宏观数据公布时即使设置止损，也不代表风险绝对固定。

对于高杠杆交易尤其危险。

# 二十九、完整空单模板

# 三十、什么时候绝对不要入场

这是你的系统里非常重要的一部分，因为激进交易者最大的损失往往不是不会找机会，而是什么都想做。

你至少要过滤掉这些情况：

- 价格处于15分钟大区间正中央；
- 上下距离关键位置都很远；
- 一根巨大K线以后直接追；
- Sweep以后没有CHOCH；
- 突破以后没有回踩；
- 止损必须放得非常远才能合理；
- RR不足1:2；
- 刚连续亏两笔；
- CPI、非农、FOMC公布前几分钟重仓；
- 因为“已经涨很多了”就猜顶，或者“已经跌很多了”就抄底。

# 最后把整套逻辑压缩成一张决策树

你以后真正看盘，可以只记这个：

```text
          价格现在在哪里？
                 │
        ┌────────┴────────┐
        │                 │
     关键位置           区间中间
        │                 │
        │                不做
        │
   出现什么行为？
        │
 ┌──────┴───────┐
 │              │
突破并站稳     Sweep后收回
 │              │
等待回踩       等待CHOCH
 │              │
小周期BOS      等待回抽
 │              │
Trend          Liquidity
Pullback       Sweep
 │              │
入场           入场
 │              │
结构失效       Sweep高/低点
作为SL         外作为SL
 │
目标≥2R
```

这其实就是我建议你建立的交易系统核心：

**位置 > 形态 > 确认 > 入场 > 失效点 > 盈亏比。**

而不是：

**指标交叉 → 买卖。**
