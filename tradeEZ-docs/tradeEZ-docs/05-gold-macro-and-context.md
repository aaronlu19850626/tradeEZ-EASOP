# 黄金宏观、事件与交易上下文

> 归档日期：2026-09-10。来源：原会话《黄金行情监控》。本文是会话资料整理，方案与参数仍属草案；所有案例数值均为教学或产品示例，非已验证业绩。

提取可复用的宏观框架；未归档短期报价、当时方向判断和未经重新核实的事件日期。

## 驱动框架

| 维度 | 原会话关注变量 | 产品用途 |
|---|---|---|
| 美元 | DXY | 记录跨市场环境 |
| 利率 | US10Y、实际利率、美联储政策 | 分析利率环境与交易表现 |
| 数据事件 | CPI、PPI、NFP、PCE、GDP、FOMC、官员讲话 | 事件距离、波动和执行比较 |
| 风险事件 | 地缘政治、VIX | 风险状态标签 |
| 能源与通胀 | Oil、通胀预期 | 记录多重驱动冲突 |

原会话的重要思路是：避险需求和利率压力可能同时存在，宏观环境用于构建条件与记录背景，不应硬编码为单变量买卖信号。

## 事件交易规则待统一

初始讨论提出数据公布后等待结构、减小仓位；蓝图则提出重大事件前后 5 分钟回避，另有 ±10 分钟统计示例。这些并非统一政策，窗口、时区和策略适用范围应配置化。

## 数据记录示例（原文节选）
# 十四、宏观内容也应该进入交易记录

特别是你的产品如果先聚焦黄金。

每笔交易自动带：

```text
Macro Context
```

例如：

```text
CPI        +15min

DXY        +0.43%

US10Y      +8bp

Gold ATR   2.3x normal

Event Risk HIGH
```

那么长期以后，你可以分析：

> 你在CPI日交易表现怎么样？

比如：

```text
CPI Days

Trades       37
Win Rate     32%
Expectancy  -0.42R
Avg Slippage 1.8x
```

平台直接告诉用户：

> 你的数据表明你不适合在重大数据发布±10分钟内交易。

这比一般风险提示有说服力得多。

# 十五、订单流也能成为结构化Trade Context

例如未来接入GC数据：

```text
Order Flow Context

Delta           +4,826
CVD Divergence  YES
Absorption      SELL
Stacked Imb.    SELL ×3
POC             4438.4
VAH             4447.2
VAL             4424.8
```

然后统计：

```text
Sweep + CHOCH
without Order Flow Confirmation

Win Rate 43%
Expectancy +0.36R
```

vs

```text
Sweep + CHOCH
+ Absorption

Win Rate 61%
Expectancy +1.27R
```

这样你最终可以**用数据验证我们现在学习的理论到底有没有Edge**。

这是非常重要的。
