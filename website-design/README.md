# TradeEZ 官网设计策划

本目录用于官网定位、内容结构、文案、页面需求和后续设计资料，独立于交易工作台的功能设计。

## 核心定位建议

TradeEZ：让每一笔交易有计划、有纪律、有复盘。

官网介绍两项互相配合的产品：

- TradeEZ EA：MT5 端的交易执行辅助与风控管理工具，介绍实际已实现并验证的下单辅助、持仓管理、风险限制和同步能力。
- TradeEZ SaaS：Web 端的交易分析与复盘平台，围绕交易归档、标签、规则检查、盘前计划、盘后总结和改进行动展开。

EA 能力以当前源码与实测为准；SaaS 能力以产品上线情况为准。已实现、开发中与规划功能必须明确区分。

## 推荐叙事

盘前建立计划 → EA 辅助执行与管理风险 → 同步交易事实 → 平台分析与复盘 → 将改进行动带入下一次计划。

强调可核对的数据、规则执行及持续改进，不承诺收益、胜率或本金安全。EA 不包装为无人值守的自动盈利机器人。

## 首页内容建议

1. 首屏：一句话价值主张、EA 与平台的真实画面、当前可用的行动入口。
2. 交易者常见问题：交易分散、执行不一致、缺少复盘、重复犯错。
3. 两项产品及其分工：EA 的执行与管理，平台的分析与复盘。
4. 完整使用流程：计划、执行、同步、复盘、改进。
5. EA 功能展示：用真实界面解释具体任务与边界。
6. SaaS 功能展示：交易日志、标签与规则、统计、每日流程；原型须明确标注。
7. 一个交易日的使用示例：包含不交易、遵守规则但亏损等真实场景。
8. 适用人群、使用条件、产品状态、常见问题。
9. 行动入口：已上线时提供下载／进入平台；未上线时提供查看演示或申请体验。

## 页面建议

首版优先：首页、EA 产品页、平台产品页、快速开始／帮助。实际开放下载、账号注册或收集联系方式前，准备相应的使用说明与隐私说明。

定价页仅在商业模式明确后建设。课程、案例库和内容中心可后续加入，不为填充网站编造用户评价、业绩或合作机构。

## 视觉方向建议

使用与 EA 呼应的深蓝灰基调，灰白文字建立层次，蓝色表达主要操作，少量金色作为品牌识别。官网需要比交易面板更疏朗，用真实产品画面与简短解释展示功能。

优先保障移动端阅读、文字对比度和加载体验。截图中的账号等信息需脱敏；模拟数据与原型界面需明确标注。
